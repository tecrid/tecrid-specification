# Changelog

All notable changes to the public TECRID specification are recorded here.

## [0.1.0] - 2026-09-01

First public draft.

- Defines TECRID terminology, trust boundaries, identifier persistence, issuance, canonicalization, Ed25519 proof, resolution, and append-only revision rules.
- Publishes JSON Schemas for issuance input, canonical issuer payloads, and resolved public records.
- Adds fictional public and controlled record examples plus a canonical signed-payload example.
- Adds machine-readable citation and software metadata for GitHub, Zenodo, and CodeMeta consumers.

[0.1.0]: https://github.com/tecrid/tecrid-specification/releases/tag/v0.1.0
